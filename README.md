# Dual screen demo

One driving view split across two browser windows: the left half and the right half of the same scene, not a map plus a view.

Open `public/index.html` in Chrome or Edge. On the left window, click **Open right side**. Fullscreen each window (F11) on side-by-side monitors of the same size. If the browser cannot place the popup, drag it to the right monitor.

Drive with W or ↑, brake with S or ↓, and steer with A/D or the arrow keys. Either window takes input. The center lane line should meet at the shared edge.
